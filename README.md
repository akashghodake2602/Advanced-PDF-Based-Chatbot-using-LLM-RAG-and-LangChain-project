# Advanced-PDF-Based-Chatbot-using-LLM-RAG-and-LangChain-project
This project converts unstructured PDF data (reports, articles, manuals) into a structured format for semantic search. It involves PDF parsing using PyPDFLoader, text chunking, embedding generation via HuggingFace’s all-MiniLM-L6-v2 model, and storing embeddings in FAISS for fast, similarity-based retrieval.
